# 设备与端差异

同一套 `em-*` 组件跑在 Android、iOS、鸿蒙、H5 与微信小程序上，最终表现由四层共同决定：HBuilderX / uni-app x 编译链、uni-app x 各端运行时、系统与厂商 ROM、UIKit 自身。UIKit 把组件层的差异收口在库内（见[平台能力与差异](./PLATFORM.md)），但编译链缺陷、平台 API 缺口与厂商 ROM 行为不在库内控制范围内。

这页记录已知的端差异：影响范围、归因方向、当前状态与可以怎么做。能绕过的给出做法，属于 uni-app x 官方的附 issue，短期处理不了的写明原因与替代路径。

> 相关页面：[平台能力与差异](./PLATFORM.md) · [常见问题](./FAQ.md) · [鸿蒙真机运行与签名](./HARMONY-REALDEVICE-RUN.md)

## 状态怎么读

| 状态 | 含义 | 你可以做什么 |
|---|---|---|
| 已修复（版本号） | 库内已修复，升级即可 | 升级到标注的版本 |
| 可绕过 | 库内不修改，按给出的做法可以正常使用 | 按「处理」列操作 |
| 上游跟踪 | 已提交 uni-app x 官方，等待修复 | 关注 issue；需要时先按「处理」列 |
| 定位中 | 已记录，正在复现并确认归因 | 按「反馈需要的信息」补充信息可加速判断 |
| 平台限制 | 平台不提供该能力，UIKit 不重复实现 | 用能力开关隐藏入口，或改用支持的端 |
| 短期不处理 | 有明确原因（依赖上游、成本或收益） | 使用替代路径 |

「定位中」不等于组件不可用：大多数情况有替代路径，或只影响特定机型；确认后会把可执行的做法补进「处理」列。

## 当前记录

| 现象 | 影响范围 | 归因 | 状态 | 处理 |
|---|---|---|---|---|
| 部分依赖系统能力的交互在鸿蒙真机上不生效或返回空结果，同版本在 Android / iOS 正常 | 鸿蒙 API 20 真机 | 疑似上游：uni-app x 鸿蒙端适配差异（需最小工程复现确认） | 定位中 | 涉及端能力的入口先用 `PLATFORM_CAPABILITIES` 按端隐藏；具体能力见[能力矩阵](./PLATFORM.md#能力矩阵) |
| 键盘弹起后底部输入栏被遮挡一截 | 荣耀机型（Android 端） | 疑似键盘高度上报与安全区口径差异（需最小工程复现确认） | 定位中 | 按「反馈需要的信息」提交机型、系统版本与键盘高度日志，便于比对 |
| 设置页显示已允许全部照片和视频，但图片选择正常、视频选择空白或返回 `1101005` | 荣耀 ALI-AN00（Android 15） | 厂商 ROM 的合并权限展示与实际权限状态不一致：设置页显示全部允许，包管理器中的 `READ_MEDIA_VIDEO` 仍为拒绝 | 可绕过 | 在系统设置中先把照片和视频权限改为禁止，再重新允许全部，强制停止并重启应用。UIKit 对权限错误提供独立提示，App 与微信小程序提供「去设置」入口，H5 展示权限说明；不要按普通选择失败或播放器问题排查 |

## 怎么判断是不是 UIKit 的问题

1. **先排除环境**：HBuilderX、UIKit、`easemob-websdk` 与小程序基础库版本是否在[环境要求](./PLATFORM.md#环境要求)范围内；App 端是否重新打过自定义基座（缺 `uni-media`、`uni-video`、`uni-openDocument` 会表现为组件失效）。
2. **判断是否只与设备相关**：同一份产物换一台同系统版本的设备是否正常。只在一台设备或一个系统版本出现，按设备差异登记，附机型与系统版本。
3. **判断是否与 UIKit 相关**：新建空白 uni-app x 蒸汽工程，只调用对应的 `uni.*` API（如 `uni.chooseVideo`、`uni.onKeyboardHeightChange`）。能复现属于上游或平台，提交 [uni-app x 官方 issue](https://issues.dcloud.net.cn/)；不能复现再在示例工程复现——能复现则属于 UIKit 行为问题，修复后会在[更新日志](/uniapp/guide/changelog)标注版本。
4. **登记结果**：确认归因后更新本页的状态与处理方式；修复后的条目迁移到更新日志并从本页删除。

## 反馈需要的信息

| # | 信息 | 用途 |
|---|---|---|
| 1 | 端：Android / iOS / 鸿蒙 / H5 / 微信小程序 | 各端能力与表现差异大 |
| 2 | 构建方式：HBuilderX 图形界面 / CLI；dev / build；是否自定义基座 | dev 与 build 的产物、后处理不同 |
| 3 | 版本：HBuilderX、UIKit、`easemob-websdk`、小程序基础库与系统版本 | 版本错配是常见原因 |
| 4 | 控制台第一条报错与完整堆栈 | 症状常是二次反应 |
| 5 | 复现步骤：从哪个页面、第几步开始 | 区分初始化、路由与数据问题 |
| 6 | 设备与系统：厂商、型号、系统版本 | 判断是否与厂商 ROM 相关 |

## 登记与更新规则

- 新条目先判定归因再登记；归因未确认时状态写「定位中」，并在「处理」列给出加速判断所需的信息。
- 修复后的条目迁移到[更新日志](/uniapp/guide/changelog)并从本页删除。
- 上游修复后删除条目，改在[能力矩阵](./PLATFORM.md#能力矩阵)标注最低版本要求。
- 「定位中」超过一个版本仍无进展时，改为「短期不处理」并写明原因与替代路径。
- 本页只记录用户无法自行判断的端差异；「这个端能不能用」由[平台能力与差异](./PLATFORM.md)的能力矩阵负责。
