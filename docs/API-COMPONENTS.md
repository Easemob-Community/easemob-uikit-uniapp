- [基础组件](./COMPONENTS-BASIC.md)：按钮、头像、徽标、文本、弹层、导航和加载反馈。
- [会话与导航组件](./COMPONENTS-CONVERSATION.md)：会话行、筛选 tab 和连接状态条。
- [聊天与消息组件](./COMPONENTS-CHAT.md)：输入栏、消息气泡、预览、快捷回复和 @ 提及。
